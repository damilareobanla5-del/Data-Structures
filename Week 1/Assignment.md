1. Meaning of Stack

A stack is a type of data structure where items are added and removed from the same end. It follows the LIFO principle, which means Last In, First Out.

This means the last item added will be the first item removed.

2. Real-Life Applications of Stack

· Web browsers: Used for the Back button to return to previous pages.

· Microsoft Word: Used for Undo and Redo operations.

· Calculators: Used to solve mathematical expressions.

· Programming: Used when running functions.

4\. Stack Operations Using an Array

Let us use an array of size 5.

Initial array:

[10, 20, 30, 40, 50]

The following operations can be performed:
Operation Result
Push(60) Stack is full
Pop() Removes 50
Peek() Shows 40
Push(60) Adds 60
Display() 10, 20, 30, 40, 60
isEmpty() False
isFull() True
5. Explanation of Stack Operations
Push: Adding a new item to the stack.
Pop: Removing the top item from the stack.
Peek: Showing the top item without removing it.
isEmpty: Checking if the stack is empty.
isFull: Checking if the stack is full.
Display: Showing all the items in the stack.
