Meaning of Stack

A stack is a type of data structure where items are added and removed from the same end. It follows the LIFO principle, which means Last In, First Out.

This means the last item added will be the first item removed.

2. Real-Life Applications of Stack

· Web browsers: Used for the Back button to return to previous pages.

· Microsoft Word: Used for Undo and Redo operations.

· Calculators: Used to solve mathematical expressions.

· Programming: Used when running functions.
